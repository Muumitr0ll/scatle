# Scatle

Igapäevane äraarvamismäng: vaata päris fotot looma väljaheitest ja arva 6 katsega, kelle oma see on. Iga katse järel saad vihjeid (klass, rühm, toit, mandrid, kaal, Eestis/elupaik). Režiimid: **Maailm** ja **Eesti**.
